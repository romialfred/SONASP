FEATURE: License form now supports 3 weight units with automatic conversion!


═══════════════════════════════════════════════════════════════════════════════
 🎯 WHAT WAS ADDED
═══════════════════════════════════════════════════════════════════════════════

  ✅ Dropdown to select unit (Grams, Ounces, Troy Ounces)
  ✅ Real-time conversion display as you type
  ✅ Automatic conversion when switching units
  ✅ Reference line showing all conversions


═══════════════════════════════════════════════════════════════════════════════
 📊 SUPPORTED UNITS
═══════════════════════════════════════════════════════════════════════════════

  • Grams (g)           = 1.00 g
  • Ounces (oz)         = 28.3495 g
  • Troy Ounces (oz t)  = 31.1034768 g  ← Default unit


═══════════════════════════════════════════════════════════════════════════════
 🧪 HOW TO USE
═══════════════════════════════════════════════════════════════════════════════

  1. Go to: /licenses/requests/new

  2. In "Planned Export Quantity" field:
     - Enter number (e.g., 500)
     - Select unit from dropdown (oz t, g, oz)
     - See automatic conversions below

  3. Example:
     Input: 500
     Unit: oz t (Troy Ounces)
     
     Reference: 15551.74 g = 548.99 oz


═══════════════════════════════════════════════════════════════════════════════
 🔄 UNIT CONVERSION
═══════════════════════════════════════════════════════════════════════════════

  You can switch units and value auto-converts!

  Example:
    1. Enter 500 in "oz t"
    2. Change dropdown to "g"
    3. Value becomes 15551.74 automatically
    4. Reference shows: 500.000 oz t = 548.99 oz


═══════════════════════════════════════════════════════════════════════════════
 💾 DATABASE STORAGE
═══════════════════════════════════════════════════════════════════════════════

  IMPORTANT: All values stored as Troy Ounces (oz t) in database

  User enters:        Database stores:
  500 g         →     16.075 oz t
  500 oz        →     455.735 oz t
  500 oz t      →     500.000 oz t
