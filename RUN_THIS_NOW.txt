📋 ÉTAPE 2: Copier et Exécuter ce Script de Diagnostic
══════════════════════════════════════════════════════════════════════════════

-- SCRIPT DE DIAGNOSTIC
SELECT '1. TABLES' as check_type,
       COUNT(*) as count,
       CASE WHEN COUNT(*) >= 2 THEN '✅ OK' ELSE '❌ MANQUANT' END as status
FROM information_schema.tables
WHERE table_schema = 'public'
AND table_name IN ('licenses', 'license_requests');

SELECT '2. VIEW' as check_type,
       COUNT(*) as count,
       CASE WHEN COUNT(*) = 1 THEN '✅ OK' ELSE '❌ MANQUANT' END as status
FROM pg_views
WHERE schemaname = 'public'
AND viewname = 'licenses_with_computed_fields';

SELECT '3. DATA IN TABLE' as check_type,
       COUNT(*) as count,
       CASE WHEN COUNT(*) > 0 THEN '✅ OK' ELSE '❌ VIDE' END as status
FROM licenses;

SELECT '4. YOUR ROLE' as check_type,
       1 as count,
       COALESCE(role, '❌ NO ROLE') as status
FROM user_profiles
WHERE id = auth.uid();

🔧 SOLUTION A: Si ligne 1 = "❌ MANQUANT"
───────────────────────────────────────────

  Tables n'existent pas → Appliquer Migration 19

  Fichier: supabase/migrations/20251108000000_create_export_license_system.sql
  
  1. Ouvrir le fichier dans votre éditeur
  2. CTRL+A (tout sélectionner)
  3. CTRL+C (copier)
  4. Retourner dans SQL Editor
  5. CTRL+V (coller)
  6. Cliquer "RUN"
  7. Attendre ~5 secondes
  8. Passer à la solution B


🔧 SOLUTION B: Si ligne 3 = "❌ VIDE"
───────────────────────────────────────

  Table vide → Insérer données échantillons

  Fichier: supabase/migrations/20251108100000_seed_license_sample_data.sql
  
  1. Ouvrir le fichier
  2. Copier TOUT
  3. Coller dans SQL Editor
  4. Run
  5. Devrait afficher: "INSERT 0 10"


🔧 SOLUTION C: Si ligne 4 ≠ "management" ou "factory"
──────────────────────────────────────────────────────

  Votre rôle ne permet pas de voir les licenses

  UPDATE user_profiles
  SET role = 'management'
  WHERE id = auth.uid();

  Exécuter dans SQL Editor, puis recharger /licenses


📋 ÉTAPE 4: Vérification Finale
══════════════════════════════════════════════════════════════════════════════

SELECT
  license_number,
  applicant_company_name,
  status,
  remaining_percentage,
  is_active,
  days_to_expiry
FROM licenses_with_computed_fields
LIMIT 3;

✅ Si vous voyez 3 lignes avec des données → SUCCÈS!
   Recharger la page /licenses dans votre application

❌ Si erreur ou 0 ligne → Vérifier:
   • Migration 19 appliquée? (SOLUTION A)
   • Migration 20 appliquée? (SOLUTION B)  
   • Votre rôle correct? (SOLUTION C)
