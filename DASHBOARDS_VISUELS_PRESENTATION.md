## 🎯 Comparaison Ancien vs Nouveau

### Terminologie

| Ancien | Nouveau | Impact |
|--------|---------|--------|
| ❌ Batch | ✅ Expédition | Plus clair |
| ❌ Batch Status | ✅ État Expédition | Professionnel |
| ❌ Active Batches | ✅ Expéditions Actives | Précis |
| ❌ In Safe | ✅ En Coffre | Français |

## 📊 Données Affichées

### Sources Principales

```
daily_production
    ├─ production_date
    ├─ estimated_oz
    ├─ bullion_grams
    ├─ estimated_fineness_pct
    └─ mining_company_id

shipping_preparations
    ├─ status
    ├─ total_weight_oz
    ├─ created_at
    └─ expedition_number

sales
    ├─ final_proceeds
    ├─ quantity_oz
    ├─ created_at
    └─ customer_id

gold_inventory
    ├─ quantity_oz
    ├─ status
    └─ location
```

### Agrégations

```
Métriques Calculées:
├─ Production YTD: SUM(estimated_oz) WHERE year = current
├─ Production MTD: SUM(estimated_oz) WHERE month = current
├─ Expéditions actives: COUNT(*) WHERE status IN (...)
├─ Stock disponible: SUM(quantity_oz) WHERE status = 'available'
├─ Revenus totaux: SUM(final_proceeds)
└─ Variation mensuelle: (current_month - prev_month) / prev_month * 100
```
