 🐛 THE PROBLEM
═══════════════════════════════════════════════════════════════════════════════

User uploads document file → File appears in "Selected Files" → Click "Next"
→ ❌ Error: "Please upload at least one document"


═══════════════════════════════════════════════════════════════════════════════
 🔍 ROOT CAUSE
═══════════════════════════════════════════════════════════════════════════════

FileUpload component expects:  onFileSelect
Code was using:                onChange ❌

Result: Callback never triggered → File never stored in state!


═══════════════════════════════════════════════════════════════════════════════
 ✅ THE FIX
═══════════════════════════════════════════════════════════════════════════════

Changed prop name from onChange to onFileSelect

BEFORE (BROKEN):
  <FileUpload
    onChange={(files) => { ... }}  ❌
  />

AFTER (FIXED):
  <FileUpload
    onFileSelect={(files) => { ... }}  ✅
  />
