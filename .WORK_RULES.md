## DATABASE RULES

### 5. SUPABASE MIGRATIONS

#### Always Include in Migration Header:
```sql
/*
  # Migration Title

  1. Changes
    - What tables/columns are being modified
    - What functions/triggers are being created

  2. Security
    - RLS policies being added
    - Permissions being granted

  3. Notes
    - Important considerations
    - Breaking changes if any
*/
```

#### Always Make Migrations Idempotent:
```sql
-- ✅ CORRECT
CREATE TABLE IF NOT EXISTS table_name (...);
DROP POLICY IF EXISTS "policy_name" ON table_name;
CREATE OR REPLACE FUNCTION function_name() ...

-- ❌ WRONG
CREATE TABLE table_name (...);  -- Will fail if already exists
DROP POLICY "policy_name" ON table_name;  -- Will fail if doesn't exist
```

### 6. ROW LEVEL SECURITY (RLS)

#### Always Enable RLS:
```sql
ALTER TABLE table_name ENABLE ROW LEVEL SECURITY;
```

#### Always Create Policies:
```sql
-- Never leave a table with RLS enabled but no policies
-- Users won't be able to access any data!

CREATE POLICY "policy_name"
  ON table_name
  FOR SELECT
  TO authenticated
  USING (true);  -- Adjust condition as needed
```

### 7. ENUM TYPES

#### Check Before Adding Values:
```sql
-- ✅ CORRECT - Check if value exists first
DO $$
BEGIN
  IF NOT EXISTS (
    SELECT 1 FROM pg_enum
    WHERE enumlabel = 'new_value'
    AND enumtypid = (SELECT oid FROM pg_type WHERE typname = 'enum_type_name')
  ) THEN
    ALTER TYPE enum_type_name ADD VALUE 'new_value';
  END IF;
END $$;

-- ❌ WRONG - Will fail if value already exists
ALTER TYPE enum_type_name ADD VALUE 'new_value';
```
