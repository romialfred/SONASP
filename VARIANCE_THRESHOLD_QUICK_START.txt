FEATURE: Configurable variance thresholds for weight confirmation

═══════════════════════════════════════════════════════════════════════

HOW TO CONFIGURE (3 STEPS)

STEP 1: Navigate to Parameters
-------------------------------
1. Login as Management user
2. Go to: Administration → Parameters
3. Click: "Business Rules" tab

STEP 2: Edit Thresholds
------------------------
You'll see three variance settings:

┌─────────────────────────────────────────────────────────────┐
│ Variance Threshold: Mine to Airport                         │
│ Default: 2.0%                                                │
│ Description: Max variance between Mine and Airport weights   │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ Variance Threshold: Airport to Refinery                     │
│ Default: 1.5%                                                │
│ Description: Max variance between Airport and Refinery      │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ Variance Threshold: Refining Loss                           │
│ Default: 5.0%                                                │
│ Description: Max weight loss during refining                │
└─────────────────────────────────────────────────────────────┘

STEP 3: Save Changes
---------------------
1. Edit the values (e.g., change 2.0 to 0.8 for 0.8%)
2. Click "Save Business Rules" button
3. Changes apply immediately!

═══════════════════════════════════════════════════════════════════════

WHAT IT DOES

When receiving gold:
✅ System calculates variance between expected and actual weight
✅ Compares variance to your configured threshold
✅ Auto-approves if within threshold
✅ Flags for approval if exceeds threshold

Example:
--------
Threshold set to: 0.8%
Expected weight: 1000g
Actual weight: 1009g
Variance: 0.9%
Result: ❌ Requires approval (exceeds 0.8%)

Threshold set to: 2.0%
Expected weight: 1000g
Actual weight: 1009g
Variance: 0.9%
Result: ✅ Auto-approved (within 2.0%)

═══════════════════════════════════════════════════════════════════════

RECOMMENDED VALUES

Conservative (High Security):
→ Mine to Airport: 0.5%
→ Airport to Refinery: 0.3%
→ Refining Loss: 3.0%

Balanced (Standard):
→ Mine to Airport: 1.0%
→ Airport to Refinery: 0.8%
→ Refining Loss: 4.0%

Flexible (Current Defaults):
→ Mine to Airport: 2.0%
→ Airport to Refinery: 1.5%
→ Refining Loss: 5.0%

═══════════════════════════════════════════════════════════════════════

WHERE IT'S USED

📍 Airport Receiving
   When: Receiving gold from mine
   Uses: Mine to Airport threshold
   
📍 Refinery Receiving
   When: Receiving gold from airport
   Uses: Airport to Refinery threshold
   
📍 Refining Process
   When: Processing/melting gold
   Uses: Refining Loss threshold
