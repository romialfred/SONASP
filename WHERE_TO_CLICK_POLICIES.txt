================================================================================
QUICK SQL ALTERNATIVE (IF POLICIES UI NOT WORKING)
================================================================================

If you really can't find the Policies UI, you can run this SQL:

Go to: SQL Editor (left sidebar, main menu)

Run this:

CREATE POLICY "Allow authenticated users all operations"
ON storage.objects
FOR ALL
TO authenticated
USING (bucket_id = 'assay-certificates')
WITH CHECK (bucket_id = 'assay-certificates');

This will create the policy directly!

================================================================================
VERIFY POLICY WAS CREATED
================================================================================

After creating (either way), verify with this SQL:

SELECT *
FROM pg_policies
WHERE tablename = 'objects'
  AND schemaname = 'storage'
  AND policyname LIKE '%assay%';

If you see a row returned = Policy exists! ✅
