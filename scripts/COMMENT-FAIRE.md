### 1. Ouvrez Supabase
- Allez sur https://supabase.com/dashboard
- Sélectionnez votre projet
- Cliquez sur **SQL Editor** (menu gauche)
- Cliquez sur **+ New query**

### 2. Copiez-Collez le SQL
- Ouvrez `scripts/CORRECTION-COMPLETE-A-EXECUTER.sql`
- Copiez TOUT (Ctrl+A puis Ctrl+C)

- Attendez 2 secondes

### 4. Vérifiez
Vous devriez voir:
```

```
