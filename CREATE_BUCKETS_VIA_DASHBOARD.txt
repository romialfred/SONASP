================================================================================
       CREATE ASSAY CERTIFICATES BUCKET - DASHBOARD METHOD
================================================================================

ERROR: "must be owner of table objects" means you need to use Supabase Dashboard
instead of SQL Editor for storage bucket creation.

================================================================================
STEP-BY-STEP INSTRUCTIONS
================================================================================

1. GO TO SUPABASE DASHBOARD
   - Open your Supabase project
   - https://app.supabase.com (login if needed)

2. NAVIGATE TO STORAGE
   - Click "Storage" in the left sidebar
   - You'll see list of existing buckets

3. CREATE NEW BUCKET
   - Click "New bucket" button (top right)
   
4. CONFIGURE BUCKET
   - Name: assay-certificates
   - Public bucket: OFF (keep private)
   - File size limit: 10485760 (10MB in bytes)
   - Allowed MIME types: application/pdf
   
5. CLICK "Create bucket"

6. CONFIGURE BUCKET POLICIES
   - Click on the "assay-certificates" bucket you just created
   - Click "Policies" tab at the top
   - Click "New policy"

================================================================================
POLICY 1: Allow authenticated users to upload
================================================================================

Policy name: Users can upload assay certificates
Allowed operation: INSERT
Policy definition:

SELECT:
Target roles: authenticated

WITH CHECK:
bucket_id = 'assay-certificates'

Click "Review" then "Save policy"

================================================================================
POLICY 2: Allow authenticated users to read
================================================================================

Policy name: Users can view assay certificates
Allowed operation: SELECT
Policy definition:

Target roles: authenticated

USING expression:
bucket_id = 'assay-certificates'

Click "Review" then "Save policy"

================================================================================
POLICY 3: Allow users to update their files
================================================================================

Policy name: Users can update their certificates
Allowed operation: UPDATE
Policy definition:

Target roles: authenticated

USING expression:
bucket_id = 'assay-certificates' AND (storage.foldername(name))[1] = auth.uid()::text

Click "Review" then "Save policy"

================================================================================
POLICY 4: Allow users to delete their files
================================================================================

Policy name: Users can delete their certificates
Allowed operation: DELETE
Policy definition:

Target roles: authenticated

USING expression:
bucket_id = 'assay-certificates' AND (storage.foldername(name))[1] = auth.uid()::text

Click "Review" then "Save policy"

================================================================================
ALTERNATIVE: SIMPLER POLICY (RECOMMENDED)
================================================================================

If the above policies are complex, use this simpler approach:

After creating the bucket:
1. Click "Policies" tab
2. Click "New policy"
3. Select "For full customization"
4. Use this template:

Policy 1 - SELECT (View):
---------------------------
CREATE POLICY "Allow authenticated uploads"
ON storage.objects FOR SELECT
TO authenticated
USING (bucket_id = 'assay-certificates');

Policy 2 - INSERT (Upload):
---------------------------
CREATE POLICY "Allow authenticated selects"
ON storage.objects FOR INSERT
TO authenticated
WITH CHECK (bucket_id = 'assay-certificates');

Policy 3 - DELETE:
---------------------------
CREATE POLICY "Allow delete own files"
ON storage.objects FOR DELETE
TO authenticated
USING (bucket_id = 'assay-certificates');
