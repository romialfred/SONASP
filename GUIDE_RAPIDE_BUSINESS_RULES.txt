AJOUTER LES RÈGLES DU COURS DE L'OR

ÉTAPE 1: Exécuter le Script SQL
--------------------------------
Fichier: ADD_GOLD_PRICE_RULES.sql

Via Supabase:
1. Dashboard → SQL Editor → New Query
2. Copier-coller le script SQL
3. Run (exécuter)

Le script ajoute 5 règles:
✅ Marge sur London AM (2.5%)
✅ Prix Minimum (1800 USD/oz)
✅ Prix Maximum (3000 USD/oz)
✅ Pourcentage Royalties (3.0%)
✅ Frais de Transport (500 USD)

ÉTAPE 2: Vérifier
------------------
Dans Supabase SQL Editor:

SELECT * FROM business_rules 
WHERE rule_category = 'gold_price';

Résultat attendu: 5 lignes

ÉTAPE 3: Rafraîchir l'Interface
--------------------------------
1. Retour à Gold Shipper
2. Rafraîchir la page (F5)
3. Administration → Paramètres → Business Rules
4. Section "Configuration du Cours de l'Or" affiche les 5 règles
