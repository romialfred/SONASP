  SUCCESS (Green) 🟢
  • Draft saved successfully

  • Changes saved

  ERROR (Red) 🔴
  • Save failed
  • Submission failed
  • Document upload failed
  • Network error

  WARNING (Amber) 🟡
  • Validation issues
  • Missing information
  • Confirmation needed

  INFO (Blue) 🔵
  • General information
  • Tips and guidance
  • System messages

 🔧 TECHNICAL IMPLEMENTATION

  Usage in Component:

  Basic Call:
  showSuccess('Title', 'Message');

  With Options:
  showSuccess(
    'Title',
    'Message',
    {
      confirmText: 'Custom Button Text',
      onConfirm: () => { /* custom action */ }
    }
  );

  Error Pattern:
  catch (err: any) {
    const errorMsg = err.message || 'Default error message';
    setError(errorMsg);
    showError(
      'Error Title',
      errorMsg + '. Additional guidance.'
    );
  }
