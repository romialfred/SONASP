  Check browser console output (F12 → Console)

  CASE 1: Shows "No active mining companies found"
    → Run this in SQL Editor:

  CASE 2: Shows database error
    → Check RLS policies:
      SELECT * FROM pg_policies WHERE tablename = 'mining_companies';

    → Add policy if missing:
      CREATE POLICY "authenticated_select" ON mining_companies
      FOR SELECT TO authenticated USING (true);

  CASE 3: Shows connection error
    → Check .env file has:
      VITE_SUPABASE_URL=...
      VITE_SUPABASE_ANON_KEY=...
