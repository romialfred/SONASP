## SLIDE 20: Refining Process - Calculations

**Title:** Final Fine Gold Calculation

**Mathematical Formula:**
```
final_fine_gold_oz = post_melting_weight_grams
                     × (fineness / 100)
                     × (metal_retained / 100)
                     / 31.1035
```

**Example Calculation:**
```
Original Export:      16,000 grams
Pre-Melting:          15,950 grams (-50g handling)
Post-Melting:         15,200 grams (-750g impurities)
Fineness Achieved:    99.9%
Metal Retained:       98.5% (1.5% refining fee)

Final Fine Gold:
  = 15,200 × 0.999 × 0.985 / 31.1035
  = 480.74 oz

Original Expected:    485.20 oz
Actual Final:         480.74 oz
Variance:             -4.46 oz (-0.92%)
Status:               ✅ Within tolerance (±2%)
```
